# Quality Gate Checklist

Every content record/page must pass all ten checks before publication.
Any failure → Review Queue. DO NOT PUBLISH.

1. **Privacy Check** — no usernames, UIDs, phone/QQ/WeChat/email, locations,
   or identifying details.
2. **Sexual Content Check** — no explicit material; sexual detail reduced to
   the minimum needed for understanding.
3. **Medical Claim Check** — no diagnosis, no treatment promises; medical
   topics carry sources + evidence strength + limitations.
4. **Duplicate Check** — no near-duplicate of existing records/pages.
5. **Evidence Check** — content correctly labeled (experience vs pattern vs
   research vs clinical vs uncertain).
6. **Source Check** — source fields filled; community material never cited as
   scientific evidence.
7. **AI Hallucination Check** — no invented specifics (DOIs, sample sizes,
   statistics, author names).
8. **Language Quality Check** — natural, professional, empathetic English;
   no AI clichés, no motivational filler.
9. **SEO Check** — unique title/description/canonical; matches real search
   intent; no keyword stuffing.
10. **Internal Linking Check** — ≥3 relevant related links (experience →
    trigger → strategy → question → research).

## Post-build verification

`npm run build` passes. Then check: links, canonical, sitemap, robots,
schema, mobile rendering, performance, accessibility.
