# Privacy Rules

Raw community material is source material only. It is never published.

## Forbidden in any published page or data file

- Usernames, display names, UIDs
- Avatars, profile images
- Phone numbers, email addresses, WeChat/QQ/Telegram IDs
- Geolocations (city-level or finer)
- Verbatim long quotes from identifiable posts
- Any cross-reference that could re-identify a person

## Allowed (after processing)

- De-identified structured facts: reported problem, trigger category, strategy
  category, reported outcome, recovery stage, lessons
- Short generic quotes (≤1 sentence) with no identifying context

## Synthetic records

Demonstration records must carry `privacy_status: "synthetic"` and display a
visible "Synthetic example record" notice on the page.
